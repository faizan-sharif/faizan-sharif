## About Me

**AI/ML Engineer** building production-grade intelligent systems — Agentic AI, RAG, GenAI, MLOps, and MCP-based tool use.

I work on AI systems that have to survive real users, real data, and real failure modes: retrieval that stays accurate, tools that fail safely, approvals before damage, and logs that explain every decision.

## What I Build

- **Agentic AI & Multi-Agent Systems** — MCP, tool use, human-in-the-loop control, evals and guardrails
- **Retrieval-Augmented Generation (RAG)** — LangChain, LangGraph, Pinecone, Chroma, context-aware retrieval over real product data
- **GenAI & LLM Systems** — OpenAI, Hugging Face, prompt engineering, structured outputs
- **MLOps & Production AI** — FastAPI, Docker, AWS, deployment, monitoring, and reliability
- **Voice & Multi-Modal AI** — Speech-to-Text, TTS fine-tuning (Coqui-TTS, Kokoro-TTS), Deepgram, voice agents
- **Machine Learning** — predictive ML, Scikit-learn, YOLOv8, OpenCV, OCR pipelines
